# 字体采样对照

日期：2026-11-16。本次对照时网站按用户要求采用 [霞鹜文楷 GB Regular v1.530](https://github.com/lxgw/LxgwWenkaiGB/releases/tag/v1.530)。对照对象为[方正教材规范楷体官方在线预览](https://www.foundertype.com/index.php/FontInfo/index/id/5399)，通过官网输入采样字并观察预览；未下载或分发方正字体。本地直接渲染霞鹜原版字体，与官网样张目视比较。两者的渲染大小、粗细和显示环境不同，此记录关注部件形态，不判定轮廓完全一致。

| 采样 | 观察结果 |
| --- | --- |
| 草、花、苗、茶、落 | 两套字体的草字头均可见一横、两竖；竖画形态、笔势及各字与下方部件的布局不完全相同。此观察不等于笔顺或字形全面合规。 |
| 心、必 | 两套字体均可辨认相关点画与主体；笔画粗细、转折和连接的视觉风格不同。 |
| 令、骨、直 | 两套字体主体结构可识别；具体笔画形状和位置有风格差异。仅凭本次目视不判定笔顺及规范性。 |

上述 10 个字是定向抽样，未对网站所有字位、教材写字表或两个字体的全部字形逐字核验，也未将方正字体等同于人教版教材正在使用的具体字体。字体作者明确提示，霞鹜文楷 GB 仍保留部分风格细节，可能不适用于义务教育图书、少儿读物和字帖等对字形要求极高的场景；参见[项目说明](https://github.com/lxgw/LxgwWenkaiGB)。练字时如与现行教材写字示范不一致，以教材为准。

霞鹜文楷 GB 使用 SIL Open Font License 1.1，网站保存原许可及附加许可声明；源 TTF 仅转换为浏览器 WOFF2，未修改字形。方正教材规范楷体为方正专有字体，官网预览仅作为目视对照，不随本项目发布。

后续更新：网站曾短暂使用猫啃硬笔楷书，随后恢复霞鹜文楷 GB，此后试用马善政毛笔楷书，曾试用演示悠然小楷，曾试用演示秋鸿楷，现试用演示春风楷并以霞鹜文楷 GB 回退缺字。本文件记录霞鹜字体的采样，不代表猫啃字体与教材或方正字体的比较结果。
