# 《现代汉语词典》在线查询验证

## 来源与方式

[商务印书馆精品工具书数据库](https://bjzs.vdict.com.cn/SY)由商务印书馆官网[列为其在线数据库](https://www.cp.com.cn/Content/2025/12-18/1633004130.html)，其产品介绍将《现代汉语词典》列入典型书目。网页搜索结果显示「现汉词典」，接口结果以 `bookId: 2` 区分该书。

在网页正常查询时观察到 `GET https://bjzs.vdict.com.cn/api/front/search/turnPage`，请求参数为 `input`（查询内容）和 `pageNo`（页码）。2026-11-14 从终端直接请求时，无需登录即返回 JSON；这是网页实际使用的接口，尚未找到公开接口文档或批量调用授权，不能假定接口稳定、支持高频或保证长期可用。

响应包含多本词典，只有 `bookId: 2` 是本次目标；匹配时同时去除结果词条名称中的 HTML 标记并与查询词精确比较。`isWord` 不能用于筛选所有精确词条：实测单字为 `true`，词语如「规矩」为 `false`。未返回目标词条不等同于证明词典原书没有收录。

## 阶段结论

按用户明确的目标，第二阶段验收对象是**可追溯地核实字词拼音**。教材仍是第一依据，词典查询以商务印书馆官方接口为主；Toocix 仅供辅助，不以其未确认版次的结果单独标记已核对。商务数据库书单及封面指向第五版；Toocix 未披露版次和原始数据来源。第二阶段的查询方式及其已知限制已记录，可以进入下一阶段，但本次没有开展教材读音核对。

## 官方接口优先：重新抽查

2026-11-14 再次从终端对 17 项做少量并发搜索：13 项在第一页返回现汉精确词条；「琴弦、静寂、捕鱼、一无所获」查完该接口返回的全部搜索页仍没有现汉精确词条。接口的拼音字段是可读文本，不需要处理详情正文的字体；返回其他词典、模糊词形或无结果都不能作为该词语核对完成的依据。

九项独立抽查中，「差、薄、重、挑、漂亮、朋友、便宜」在已返回的精确词条中与商务平台读音集合一致；「行、树行子」存在对应差异。商务平台为「行」提供 háng、hàng、héng、xíng，并给出「树行子」shùhàng·zi；[Toocix 的「行」相关条目](https://toocix.com/api/modern-dict/entries/19824)与[「树行子」](https://toocix.com/api/modern-dict/entries/46898)分别标为 háng 和 shùháng·zi。Toocix 版次未知，不能据此断定差异原因，也不能以单方结果替代教材与官方核对。部分 Toocix 搜索只检查第一页，上述一致性不代表全部读音已经穷尽。

[publisher_lookup.py](../scripts/publisher_lookup.py) 查询官方搜索接口、筛选 `bookId=2` 和精确词形、保留不同词条 ID 与读音，并记录搜索分页是否穷尽；对超时及服务端错误有限重试，遇 401、403、429 停止。样本「行、树行子、规矩、朋友、琴弦」均完成接口所报页数的查询，前四项找到精确词条，「琴弦」未找到；后者不等于证明原书未收录。示例：`python3 scripts/publisher_lookup.py --output /tmp/publisher.jsonl 行 树行子 规矩 朋友 琴弦`。输出只作为候选及追溯记录，结合教材语境才能确定取哪个音；详情可能需要已登录权限。该接口是网页实际使用的接口，批量使用许可、限额及长期稳定性仍未获确认；小样本成功不等于无限量查询许可。

## 登录后复测

2026-11-14 用户登录后，在原浏览器会话中实际查询「奔」与「规矩」，其《现代汉语词典》详情页面分别显示 bēn 的四个义项和「规矩」的两个义项，说明本次会话可以在页面上阅读这些完整词条；该结论不推广为所有词条和所有后续会话均有权限。

正常打开词条页面时，浏览器观察到 `GET /api/front/item/detail/{词条ID}` 返回成功，响应包含拼音列表、`info.infoHtml` 和字体资源信息。对于「奔」，页面视觉上显示可读正文，但接口原始 HTML 和无障碍文本中的释义字符与视觉正文不一致；页面同时加载专用 WOFF 字体。登录状态、令牌、个人信息均未记录。

### 编码与小批量测试

字体的字符映射表将接口字符对应到字形，测试的字体字形名以 `uni` 加原字符 Unicode 值命名，可从字形名还原文字。使用登录会话连续查询「挎、奔、规矩、不料、衣裳」共 5 项，分别取得搜索结果及详情；「奔」的 bēn、bèn 通过各自 ID 查询，共取得 6 个读音条目。用各条详情关联字体解码义项，依次为 2、4、4、2、1、1 个，样本义项没有未映射汉字；「奔」两种读音及「规矩」的义项与网页视觉显示逐项一致。样本小，不能证明全部特殊字形、完整例句及其他条目无误。不能将本次小批量成功视为大规模使用授权或可长期使用的承诺。

可复现的探索脚本为 [dictionary_sample.js](../scripts/dictionary_sample.js) 与 [dictionary_decode.py](../scripts/dictionary_decode.py)：前者在已登录页面按固定样本查询并返回原始数据，后者读取本地保存的 JSON 并下载该条目的字体解码；解码时报告未映射汉字。它们是小样本原型，尚未验证任意词目、所有字形及批量许可，不能作为已经完成的全量核对工具。测试原始词典正文和登录凭据不应提交到公开仓库。

## 候选：汉语辞书资料平台

2026-11-14 发现第三方[汉语辞书资料平台](https://toocix.com/modern/)。其网页自称结构化整理《现代汉语词典》，提供词条详情及原书页影像；页面未明确说明所用版次或获得出版社授权的情况，网站说明限定内容用于学术检索与研究。不能因名称相同就将其视作出版社原版。

正常网页交互中观察到 `GET https://toocix.com/api/modern-dict/entries?q=查询词&limit=30&offset=0` 和 `GET https://toocix.com/api/modern-dict/entries/{词条ID}`：前者返回搜索候选，后者返回拼音、印刷页码、义项、例句和其他字段；未发现公开接口文档。搜索还会匹配释义及例句，必须逐项校验返回词目与查询词完全相同；未在第一页出现不等于词典没有收录。

从终端以最多三个并发请求测试「挎、奔、规矩、不料、衣裳、静寂、捕鱼、一无所获」：前五项找到精确词目并可取得详情，其中「奔」有 bēn 和 bèn 两条，各返回四个义项；后三项在搜索结果第一页未找到精确词目。此测试表明少量并发请求可用，不证明全部条目覆盖、高频批量调用许可或服务稳定性。

平台「规则」条目显示第 491 页，页面影像的版式与已查看的商务印书馆第七版第 491 页样照一致；「点燃、萌发、团结、团圆、中断、兔」六个候选词条的页码和拼音也与已查看的第七版样页对应。以上是有限样本，只能证明相符，不能证明整库版次、来源和转录完全可靠。平台自身对「良性肿瘤」一条标注扫描不清、末尾文字有疑问，说明自动转录不能不经核实地视为原书完整义项。

用户明确第二阶段服务于字词拼音核对。2026-11-14 通过 Toocix API 查询「挎、奔、规矩、不料、衣裳」，并与本次会话取得的商务印书馆第五版 API 拼音比较：kuà、bēn、bèn、guī·ju、bùliào、yī·shang 这六个读音逐一相同。搜索项「奔、规矩、衣裳」分别翻完 4、2、2 页后再次取得相同精确词目；「挎」和「不料」各一页即可查完。搜索结果会匹配释义，精确词形及读音仍须逐项辨别，不能把模糊命中当作答案。对六个读音对应的 14 条义项逐一比较，去掉标点后有 11 条文字一致、3 条不同；这些差异可能影响语境判断，不能自动判断原因或将数据视作同一版。这里的 14 条按「挎」2、「奔」两个读音各 4、「规矩」2、「不料」1、「衣裳」1 计数。
