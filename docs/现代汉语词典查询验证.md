# 《现代汉语词典》查询方式与验证

验证日期：2026-11-14。教材直接注音优先；需要词典补充时，以商务印书馆查询结果及适用义项为依据。Toocix 仅作辅助线索，不能单独用于确认读音。两个渠道的使用限制和测试范围如下；查询命中不等于已完成教材语境核对。

## 商务印书馆官方查询

[商务印书馆精品工具书数据库](https://bjzs.vdict.com.cn/SY)由[出版社列为在线数据库](https://www.cp.com.cn/Content/2025/12-18/1633004130.html)，其产品介绍收录《现代汉语词典》。平台使用的封面和[中山大学图书馆书单](https://library.sysu.edu.cn/eresource/4611)标为第五版；未逐条核实线上内容与该版印次完全一致，不得标为第七版。

网页实际使用的搜索接口为 `GET https://bjzs.vdict.com.cn/api/front/search/turnPage?input=字词&pageNo=1`。2026-11-14 少量终端查询无需登录即可取得 JSON；读音字段是可读文本。结果中须选择 `bookId=2`，去除名称中的 HTML 后精确比较词形，保留所有同形词条的 ID、读音和对应摘要。`isWord` 不能用来筛选所有精确词条：实测单字为 `true`，词语「规矩」为 `false`。

对 17 项做少量并发搜索，13 项在第一页返回现汉精确词条；「琴弦、静寂、捕鱼、一无所获」查完接口返回的全部搜索页仍无精确词条，不代表原书未收录。多音字「行」返回 háng、hàng、héng、xíng，「树行子」返回 shùhàng·zi；「规矩」「朋友」分别返回 guī·ju、péng·you。不同词义与语境仍须逐项判断。

[publisher_lookup.py](../scripts/publisher_lookup.py) 可小批量查询、按来源和词形筛选、保留不同读音及词条 ID、翻页并记录是否穷尽；逐词保存 JSONL 以便续查。超时及服务端错误有限重试，遇 401、403、429 停止。示例：

```bash
python3 scripts/publisher_lookup.py --output /tmp/publisher.jsonl 行 树行子 规矩 朋友 琴弦
```

上述五项实测均查完接口所报页数，前四项有精确词条，「琴弦」没有。测试使用模拟响应检查匹配、分页、异常和限流；API 返回结果只是候选，不能凭工具成功或摘要命中标记已核对。详情可用于判断义项，但可能需要登录。

用户登录后，「奔」和「规矩」的详情分别显示 bēn 的四个义项和「规矩」的两个义项。详情接口返回的 HTML 字符需配合专用字体显示；[dictionary_sample.js](../scripts/dictionary_sample.js) 和 [dictionary_decode.py](../scripts/dictionary_decode.py) 曾用五项样本验证字形名映射，其中「奔」两种读音和「规矩」的义项与网页显示逐项一致。这两个脚本是小样本探索工具，未验证所有字形，使用时须检查未映射字符，不能将解码结果直接当成已核对证据。

接口是网页使用的内部接口，未找到公开 API 文档、个人账户自动化查询限额或批量使用许可；不能从小样本成功推断长期稳定或无限量使用。天津大学图书馆对其[机构电子资源平台](https://eds.tju.edu.cn/ermsClient/eresourceInfo.do?rid=1)禁止批量下载，这是该机构的规定，不能直接推定适用于个人账户。开展大批量查询前须确认适用条款。测试数据、账号和凭据不提交到仓库。

## Toocix 辅助查询

[Toocix 平台](https://toocix.com/about/)称其结构化整理《现代汉语词典》，支持跨词条检索，但未说明原始数据来源、具体版次或项目用途的 API 许可；平台说明内容仅供学术检索与研究使用。

观察到的接口是 `GET https://toocix.com/api/modern-dict/entries?q=查询词&limit=30&offset=0` 与 `GET https://toocix.com/api/modern-dict/entries/{词条ID}`。搜索同时匹配词形、释义及例词，必须再核对精确词形；详情中的 `senses` 为空时还需检查 `definition`。未查完分页或未命中不能判为原书无该词。[toocix_sample.py](../scripts/toocix_sample.py) 保留分页、ID、失败记录和有限重试，并在访问受限或限流时停止。

接口测试曾对「不料」「衣裳」发生 TLS 握手超时，重试后成功；这只证明样本恢复，不保证服务稳定。「挎、奔、规矩、不料、衣裳」五项的六个读音与商务平台结果一致；对应 14 个义项去掉标点后 11 个文字一致、3 个不同。样本不能证明全库一致，义项差异原因未确认。

九项拼音抽查中，「差、薄、重、挑、漂亮、朋友、便宜」的已返回精确词条与商务平台读音集合一致；「行、树行子」有对应差异：[Toocix 的「行」相关条目](https://toocix.com/api/modern-dict/entries/19824)和[「树行子」](https://toocix.com/api/modern-dict/entries/46898)标为 háng、shùháng·zi，商务平台对应为 hàng、shùhàng·zi。部分 Toocix 查询只检查第一页；差异可能涉及版次或整理，不能推定原因。

此前有限样本「点燃、萌发、团结、团圆、中断、兔」的 Toocix 页码和拼音与第七版样页相符，但不能证明全库版次或来源；平台自身也对「良性肿瘤」条目标注原文不清、末尾存疑。故 Toocix 结果只能提示复核，教材和商务印书馆仍是项目指定的依据。
