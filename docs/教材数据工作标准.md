# 教材数据工作标准

本标准依据项目需求和已有工作的经验制定，用于验收一至六年级语文教材数据。先判断交付是否满足标准，再选择执行方法。发生冲突时，以用户最新明确指令为准。

## 目标与范围

以统编版人民教育出版社小学语文教材为基础，整理一年级至六年级、上册和下册的写字表、词语表、古诗词和日积月累；逐项核对字词及正文的拼音，供记忆和练字使用。教材是第一信源，《现代汉语词典》是第二信源；不以其他来源替代两者。

## 交付标准

### 第一阶段：官方教材 PDF

- 从国家中小学智慧教育平台直接下载人教版语文教材 PDF，一至六年级每年级上、下册各一份，共 12 份。第三方镜像和由网页图片重新拼成的 PDF 不能冒充平台下载的原始 PDF。
- 每份记录年级、册次、平台教材页面及实际下载来源、平台显示的版本信息、下载日期、文件大小、页数和 SHA-256；版本信息未明确时如实标注，不因文件更新时间推定版次。
- 对每份文件检查能否正常打开、页数与平台所示一致，抽查首尾页和目录，确认册次对应；无法取得或无法验证的项目明确列出。
- 12 份文件及对应清单提交至指定 GitHub 仓库，核实远程提交包含完整文件，文件可下载并通过校验；不得仅提交链接、清单或本地路径。

**验收条件：**12 份官方原始 PDF 均已下载、检查并提交到远程，逐册信息和校验结果可查。任一文件缺失、来源或完整性未确认、远程提交未成功，第一阶段均未完成。

### 第二阶段：《现代汉语词典》查询方式

- 找到网上可用的《现代汉语词典》查询版本，优先 API；记录提供方、词典版本、入口、可用性和使用限制。
- 实际查询有代表性的单字、词语、多音字和轻声词，检查结果能否提供读音和必要义项，并测试能否批量查询及追溯结果。
- 没有可用 API 时，如实说明，提供经实际测试可用的在线查询方式及其限制；不可用的入口、未验证的接口或其他词典不能计为完成。

**验收条件：**提供经实测可用的查询方式和测试结果，清楚说明能否批量处理及其限制。

### 第三阶段：数据、核对与部署

- 两份 CSV 分别交付字词和诗词、日积月累，包含既定表头、稳定 ID、年级、上下册、名称、对应内容、拼音和供人查看的核对状态。字段结构遵循项目 README；状态不显示在页面。
- 与第一阶段教材逐册、逐课、逐栏目比较，检查覆盖、归属、顺序及正文；已确认遗漏的内容补入，无法确认的内容留空并标明，不用猜测填充。
- 对每个汉字、词语和正文中每个字音独立核对。教材直接标音时以教材为准；教材未标音时，依据《现代汉语词典》并结合具体词义和语境核对。不同课文、不同词义的同字或同词须分别确认，不能仅凭同形自动判定。
- 遇到分歧时记录具体字词、教材或词典的不同读法及采用依据；教材和词典不能确定的部分留空并标注。来源不可访问、未查询或未核实的项目不得标为已核对。
- 核对状态可供逐行查看；若一行包含多个字词，须另有可追溯到具体项目的核对记录，不能用一条笼统状态代替每个读音的证据。进度按同一口径分别统计已核对、有分歧、缺失或未核，注明统计单位。
- 提交两份 CSV 及必要核对记录，按项目构建方式生成网站并推送部署；检查构建结果、GitHub Pages 部署状态，以及线上代表性字词和诗词页面的内容、拼音和访问。

**验收条件：**12 册教材的范围均已逐项处理，每个读音的实际状态与证据可追溯；分歧已标注、缺失已留空；CSV 与线上页面一致，远程提交和部署均经验证。

## 执行标准

1. **顺序不可跳过。**先完成并验收第一阶段，再开展第二阶段；第二阶段验收后才进行第三阶段。第一阶段有未完成项时，不转做词典查询或词条核对。用户明确另行安排的工作除外。
2. **先验证依赖，再批量执行。**第一阶段先确认平台下载入口和访问权限，再下载全套并逐册验收；第二阶段先用代表性查询验证可用性和限制，再确定批量核对方式。
3. **按册、按批次处理。**以一册教材或可核验的一批词条为工作单位，批量提取、比对和记录；对多音字、轻声、儿化、变调、古文语境及来源冲突逐项判断。机械统计和结构校验可用程序完成，但程序生成候选或形式匹配不等于独立核对。
4. **只用指定信源作结论。**教材优先，词典补充；不把第三方转录、类似例句、猜测、程序输出或其他资料当作核对结论。教材版本、词义或读音不能确认时如实记录，继续处理不依赖该疑点的其他项目。
5. **明确状态和证据。**区分实际下载与查看、直接注音与语境判断、已查询与已核实。状态只反映已完成的核对；一处疑点不得掩盖同一行其他项目的完成情况。
6. **在验收点提交。**每阶段形成完整、可检查的结果后提交；提交前检查工作区，保护其他未提交修改；提交后检查远程结果。对网络中断或权限不足，记录具体失败环节与已完成部分，不声称成功。
7. **按交付衡量进度。**分别报告三个阶段是否达到验收条件，以及第三阶段各类项目数量；不得将注释增加、候选生成或局部参考视为整项完成。

## 当前边界

截至本标准制定时，整理使用的第三方 PDF 副本不满足第一阶段的官方来源要求；12 份官方原始 PDF 尚未完成下载、验收和提交。后续第一阶段完成前，不开展第二、第三阶段工作。
