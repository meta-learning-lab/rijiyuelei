# 一笔一画，日积月累

一个用于小学汉字、词语和古诗记忆与练字的简单网站。使用静态文件运行，例如在此目录执行 `python3 -m http.server 8000 --directory dist`，然后访问 http://localhost:8000。

## 内置数据

网站读取两份 UTF-8 CSV，当前只包含演示内容，未按教材核对。正式整理后可以替换文件内容。

### 字词：`dist/words.csv`

每课一行，表头为 `ID,年级,学期,课文,汉字,汉字拼音,词语,词语拼音`。汉字连续填写；词语用竖线 `|` 分隔。「汉字」或「词语」可单独留空。汉字拼音按字用空格分隔；词语拼音按词用 `|` 分组、每个字的拼音用空格分隔。未经核对的拼音应留空。

### 诗词：`dist/poems.csv`

古诗或日积月累每条一行，表头为 `ID,年级,学期,标题,朝代,作者,正文,正文拼音`。正文和正文拼音中的 `\n` 表示换行，拼音逐字用空格分隔；朝代、作者及未经核对的拼音可以留空。

每条记录必须有稳定的 ID，同一文件内不可重复；只能使用字母、数字、下划线或连字符，已分配的 ID 不要重新使用。年级填写「一年级」至「六年级」，学期填写「上册」或「下册」。包含英文逗号、引号或实际换行的字段须遵守 CSV 转义：用双引号包围字段，字段内双引号写成两个双引号。导入教材数据前应核对版本、课文归属和准确性。

每次修改 CSV 或页面后，执行 `python3 scripts/build_routes.py`，重新生成静态内容页面。脚本会校验 ID、年级、学期及路径字段，并重建 `dist/words/` 和 `dist/poems/` 目录；这两个目录只存放生成文件。

链接格式为 `/words/ID/年级/学期/课文/` 或 `/poems/ID/年级/学期/标题/`。ID 用于识别条目，名称、年级或学期变更会改变完整路径；静态页面不会自动保留旧路径。

正文优先使用设备自带的楷体；不同设备的字体可用性不同。
